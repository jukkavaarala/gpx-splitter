GPX Splitter Help

Getting started

Open Show Files, then use Upload GPX in the files window to select one or more GPX files. Uploaded tracks are drawn on the map and added to the file list.

Edit course
  • Open Edit Course to see the start and finish line status.
  • Select Add Start Line or Add Finish Line, then click two points on the map to draw the line. Existing lines can be replaced with Edit Start Line or Edit Finish Line.
  • Use Clear All Lines to remove both lines. You will be asked to confirm before they are cleared.
Files and laps
  • Use the file list to show or hide tracks, select a track or lap as the analysis baseline, view file information, or remove files.
  • Use Crop GPX Files after drawing the course start and finish lines to create lap files. Undo Crop restores the original files.
  • The file list groups laps under their original GPX file. Use the group arrow to expand or collapse the laps.
Track analysis
  • Choose the baseline with the chart icon in the file list. The baseline color is shown consistently on the map, file list, and analysis.
  • Select Analyze Tracks to compare visible tracks against the selected baseline.
  • The analysis window shows the time differences by distance, a legend with live deltas during playback, and summary statistics.
Playback
  • Open the playback window with Show Playback.
  • Use play/pause, stop, the speed selector, and the progress slider to control playback. Playback runs for the visible tracks.
  • Smooth movement controls marker movement between points, and Follow location keeps the map centered on playback.

Panels can be moved by dragging their headers and resized from the bottom-right corner.
