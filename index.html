GPX Splitter Help

Getting started

Open Edit Tracks to manage tracks. Use Upload GPX in the files window to select one or more GPX files. Uploaded tracks are drawn on the map and added to the file list.

Edit course
  • Open Edit Course to see the start and finish line status. The button keeps the same label whether the panel is open or closed.
  • Select Add Start Line or Add Finish Line, then click two points on the map to draw the line. Click the active button again to cancel drawing. Existing lines can be replaced with Edit Start Line or Edit Finish Line.
  • When a line is set, use its Show on map link to move the map to that line.
  • Use Clear All Lines to remove both lines. You will be asked to confirm before they are cleared.
Files and laps
  • Use Edit Tracks to open or close the track-management window. The button keeps the same label in both states.
  • In the file list, use the visibility, baseline, information, and remove buttons to manage tracks and laps.
  • Use Crop Tracks after drawing the course start and finish lines to create lap files. Undo Crop restores the original files.
  • The file list groups laps under their original GPX file. Use the group arrow to expand or collapse the laps.
Track analysis
  • Choose the baseline with the chart icon in the file list. The baseline color is shown consistently on the map, file list, and analysis.
  • Select Analyze Tracks to compare visible tracks against the selected baseline.
  • The analysis window shows time differences by distance, a legend with deltas relative to the baseline, and summary statistics.
  • The analysis refreshes automatically when tracks are added, removed, hidden, or when the baseline changes. The chart can be resized and remains sharp when the panel size changes.
Playback
  • Open or close the playback window with Playback. The button keeps the same label in both states.
  • Use play/pause, stop, the speed selector, and the progress slider to control playback. Playback runs for the visible tracks.
  • Smooth movement controls marker movement between points, and Follow location keeps the map centered on playback.
  • Playback markers use precomputed smoothed track paths, while the original track data is retained for analysis.

Panels can be moved by dragging their headers and resized from the bottom-right corner.
