GPX Splitter Help

Getting started

Upload one or more GPX files with Upload GPX. Tracks are drawn on the map and appear in the file list.

Map controls
  • Use Add Start Line and Add Finish Line, then draw each line on the map.
  • Use Clear Lines to remove the start and finish lines.
  • Use Show Files to show or hide loaded files. File and lap visibility can be changed in the file list.
Laps and analysis
  • Select a track or lap as the baseline in the file list.
  • Use Crop GPX Files after drawing start and finish lines to create lap files. Undo Crop restores the original files.
  • Select Analyze Tracks to compare visible tracks against the selected baseline.
Playback
  • Open the playback window with Show Playback.
  • Use play, pause, stop, speed, and the progress slider to control playback.
  • Smooth movement interpolates marker movement, and Follow location keeps the map centered on playback.

Panels can be moved by dragging their headers and resized from the bottom-right corner.
